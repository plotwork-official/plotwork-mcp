# Plotwork MCP server

The local [Plotwork](https://plotwork.dev) MCP server, published to npm as `@buun_group/plotwork-mcp`. It gives an AI agent tools that draw, check, convert, and sync diagrams, over standard input and output, with no API key.

This repository holds the built package and its release workflow. The first release has not been published yet.
